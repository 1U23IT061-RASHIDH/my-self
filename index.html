1. Basic HTML Structure

These tags create the basic structure of every HTML webpage. 

<!DOCTYPE html>
<html>
<head>
    <title>My Website</title>
</head>

<body>

    <h1>Hello World</h1>

</body>
</html>
Tag Explanation
<!DOCTYPE html> Tells the browser that the document uses HTML5.
<html> Root element of an HTML page.
<head> Contains webpage information and resources.
<title> Sets the browser tab title.
<body> Contains visible webpage content.

2. Head Tags

<meta>

Provides information about the webpage. 

<meta charset="UTF-8">

<meta name="viewport"
      content="width=device-width, initial-scale=1.0">

<link>

Connects external CSS files. 

<link rel="stylesheet" href="style.css">

<style>

Adds CSS directly inside HTML. 

<style>

    h1 {
        color: blue;
    }

</style>

<script>

Adds JavaScript. 

<script>

    alert("Hello");

</script>

9. Div and Span

<div>

A block-level container used to group content. 

<div>

    <h2>About Me</h2>

    <p>I am an MCA student.</p>

</div>

<span>

An inline container used for styling or grouping small portions of content. 

<p>

    My name is
    <span>Rashidh</span>.

</p>

My name is Rashidh .

10. Semantic HTML Tags

Semantic tags clearly describe the purpose of their content. 

<header>
    Website Header
</header>

    Section

    Article
</article>

    Sidebar

Tag Purpose
<header> Top/header content.

<main> Main content.
<section> Content section.
